\chapter*{Abstract}
\vspace{0.5cm}
\hrule
\vspace{0.5cm}

Modern coding agents can autonomously read code, propose fixes, and run test suites, but their performance is bounded by their ability to retrieve relevant context. As repositories grow to millions of tokens, this retrieval step becomes a major constraint. Existing retrieval methods match code by surface-level similarity, overlooking the structural dependencies that link functions across files. This thesis introduces CodeGraph, a hybrid retrieval system that uses source-code structure for agent navigation. The system extracts lexical starting points from task descriptions and propagates relevance through a dependency graph using Personalized PageRank, providing agents with a ranked and inspectable view of the codebase.

CodeGraph achieves 74.0\% Recall\@10 on SWE-bench Lite, a benchmark of 300 real software issues, representing a 24.3 percentage point improvement over the competitive BM25-only baseline. Lexical matching is sufficient to locate the general region of the codebase, while graph propagation is necessary to rank the structurally related files once that region is reached. This sets a clear ceiling on retrieval: if no starting point lands in the correct neighborhood, graph propagation has nothing to amplify. The thesis contributes a Tree-sitter parsing pipeline, a Python code graph schema, a deterministic PPR retrieval engine, and MCP/CLI interfaces for AI coding agents.
