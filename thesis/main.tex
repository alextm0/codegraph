\chapter*{Abstract}
\vspace{0.5cm}
\hrule
\vspace{0.5cm}

LLM-based coding agents are increasingly capable of resolving real software engineering tasks, moving beyond simple code generation to the autonomous management of entire repositories. However, as codebases grow to millions of tokens, the effectiveness of these agents is strictly limited by their ability to navigate complex file structures. Traditional retrieval methods, such as keyword search or dense embeddings, treat code as flat text and often fail to bridge the gap between a natural-language issue and its structural root cause. This thesis introduces CodeGraph, a hybrid retrieval system that leverages the inherent graph structure of source code to facilitate agentic navigation. By extracting lexical seeds from task descriptions and propagating relevance through a dependency graph using Personalized PageRank, CodeGraph provides agents with a deterministic and structurally-grounded view of the codebase.

The system was validated on SWE-bench Lite, a benchmark of 300 real-world software issues. CodeGraph achieved a 74.0\% Recall@10, marking a substantial 32-percentage-point increase over traditional lexical search. These results prove that while initial seed quality is a critical bottleneck, leveraging the structural dependency graph of the source code allows agents to pinpoint relevant files within complex repositories. By transforming a codebase into a navigable map of logical links, this work establishes that explicit structural context is a fundamental requirement for the next generation of autonomous coding agents.
