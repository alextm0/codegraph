\begin{frame}{The Ambiguity of Natural Language in Agentic Coding}
    \begin{itemize}
        \item \textbf{The Everyday Reality:} Developers increasingly rely on AI agents to navigate large repositories.
        \item \textbf{The Friction Point:} Natural language queries are often abstract (e.g., "fix the permissions logic").
        \item \textbf{The Vocabulary Mismatch:} The prompt rarely matches exact identifiers like \texttt{global\_settings.py}.
        \item \textbf{The Result:} Pure text similarity struggles with this ambiguity. We must leverage structural execution semantics instead.
    \end{itemize}
