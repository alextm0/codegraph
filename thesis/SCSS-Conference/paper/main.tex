\begin{abstract}
AI coding agents require precise repository-scale retrieval to locate relevant context. Traditional keyword search and dense retrieval treat code as text, ignoring structural dependencies like imports, calls, and inheritance hierarchies. We present CodeGraph, a hybrid retrieval system that combines lexical seeding with Personalized PageRank over a repository-level dependency graph. On SWE-bench Lite, CodeGraph achieves 74.0\% Recall@10, improving upon a BM25 baseline by 24.3 percentage points. Our analysis shows that lexical matching is best used to place starting points, while structural propagation determines the relevance of the surrounding neighborhood. We find that seed reachability, rather than downstream ranking sophistication, determines the retrieval performance ceiling.
\end{abstract}
