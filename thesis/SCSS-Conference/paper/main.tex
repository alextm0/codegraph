\title{CodeGraph: Repository-Level Structural Retrieval for AI Coding Agents via Personalized PageRank}

\author{\IEEEauthorblockN{Toma Alexandru-Mihai}
\IEEEauthorblockA{\textit{Computer Science Department} \\

alexandru.toma2@stud.ubbcluj.ro}

\maketitle

\begin{abstract}
AI coding agents require precise repository-scale retrieval to locate relevant context. Traditional keyword search and dense retrieval treat code as text, ignoring structural dependencies like imports, calls, and inheritance hierarchies. We present CodeGraph, a deterministic repository-level retrieval system that combines lexical seed selection with Personalized PageRank over a static dependency graph. On SWE-bench Lite, CodeGraph achieves 74.0\% Recall@10, improving upon the strongest lexical BM25 baseline by 16.0 percentage points. Our analysis shows that lexical matching is best used to place starting points, while structural propagation determines the relevance of the surrounding neighborhood. We find that seed reachability, rather than downstream ranking sophistication, determines the retrieval performance ceiling.
\end{abstract}
