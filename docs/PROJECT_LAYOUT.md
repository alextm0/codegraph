# Repository layout

Full map of the CodeGraph monorepo. Use with [reference/module-map.md](reference/module-map.md) for `src/codegraph/` internals.

```
codegraph/
├── AGENTS.md              # Short agent MCP guide (points to docs/)
├── CLAUDE.md              # Dev conventions for AI assistants
├── README.md              # User-facing quick start
├── config.yaml            # Active project config (generated by init)
├── .env                   # NEO4J_PASSWORD (gitignored; see .env.example)
├── pyproject.toml         # Package, deps, entry points
│
├── docs/                  # ← SOURCE OF TRUTH for agents (this tree)
├── thesis/                # LaTeX thesis (chapters, assets, ai_workflow/)
├── evaluation/            # SWE-bench harness, results/, dashboard/
├── frontend/              # Visualizer UI (Vite + React + D3)
├── projects/              # Optional cloned repos (init / visualizer)
│
├── src/codegraph/         # Main Python package
│   ├── cli/               # Typer CLI
│   ├── core/
│   │   ├── parser/        # language-agnostic orchestration
│   │   ├── languages/     # tree-sitter extractors and resolvers per language
│   │   ├── graph/         # Neo4j + GDS + Cypher queries
│   │   └── retrieval/     # Seeds, PPR pipeline, formatting
│   ├── mcp/               # FastMCP server (2 tools)
│   ├── visualizer/        # FastAPI app for UI
│   ├── watcher/           # Incremental file updates
│   └── utils/             # config, paths, ignore, logging
│
├── tests/
│   ├── unit/              # No Neo4j required (most tests)
│   ├── integration/       # MCP, visualizer HTTP
│   ├── fixtures/          # user_auth (primary), flask (large)
│   └── conftest.py        # neo4j_required marker
│
└── docs/CodeGraphContext-Docs-From-Github/  # Reference only — NOT our spec
```

## Entry points (`pyproject.toml`)

| Command | Module | Purpose |
|---------|--------|---------|
| `codegraph` | `codegraph.cli.main:cli` | Main CLI |
| `codegraph-mcp` | `codegraph.mcp.server:main` | MCP stdio server (alias) |
| `codegraph-bench-dashboard` | `evaluation.dashboard.app:main` | Textual eval dashboard |

## Optional install extras

```bash
pip install -e ".[dev]"          # pytest
pip install -e ".[bench]"        # datasets, gitpython — SWE-bench runner
pip install -e ".[dashboard]"    # textual — bench dashboard
pip install -e ".[visualizer]"   # fastapi, uvicorn — visualize command
```

## Generated / local artifacts

| Path | Purpose |
|------|---------|
| `.codegraph_cache/` | Cloned SWE-bench repos during evaluation |
| `evaluation/results/` | Benchmark JSONL + summary.json per run |
| `frontend/dist/` | Built UI served by visualizer (after npm build) |
